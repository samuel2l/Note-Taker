# Note-Taking 
 It allows users to **automatically transcribe speech into structured notes**, enabling real-time note-taking during lectures or conversations.

##  Purpose

Designed to help students focus on learning while the system listens and takes notes for them. This feature works hands-free.

## ⚙️ Features

- 🎤 **Voice-activated recording** of lectures and conversations
- 💾 **Persistent storage** of notes for review and study


##  How It Works

1. The system listens for voice input or is triggered by a gesture or command.
2. The user uses speech to decide next course of action ie. to find a course,record audio or access audio
